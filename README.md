# ERP Siumang User Manual - Documentation Build

Repositori ini berisi hasil *build* produksi untuk dokumentasi **User Manual ERP Siumang**.

## Tentang ERP Siumang
ERP Siumang merupakan sistem ERP kustom yang dikembangkan berbasis pada **ERPNext** (Frappe Framework). Dokumentasi ini mencakup panduan penggunaan untuk berbagai modul seperti:
- Purchasing & Procurement
- HRIS & Payroll
- Accounting & Finance
- Inventory Management
- Production & Manufacturing
